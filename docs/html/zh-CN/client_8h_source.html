281 /**
282 * @~English
283 * @brief Enable or disable dynamic TX power adjustment based on RSSI.
284 * @details This feature is **enabled by default** and **highly recommended** to keep enabled.
285 * When enabled, the client periodically reads the peer's RSSI during @ref Update() and adjusts
286 * the local BLE transmit power using a hysteresis quantizer:
287 * - Strong signal (high RSSI) → Lower TX power to save energy and reduce interference.
288 * - Weak signal (low RSSI) → Higher TX power to maintain connection stability.
289 * **Conflict with manual power:** When dynamic adjustment is enabled, any value set via
290 * @ref set_local_tx_power() will be **overwritten** and not take effect. To use a fixed manual
291 * TX power, you must first disable this feature by calling `set_dynamic_tx_power_enabled(false)`.
292 * @note On ESP32, this feature relies on @ref NimBLEClient::getRssi(). Due to severe RSSI fluctuation (drift)
293 * in ESP32 Arduino Core versions **older than 3.1.0**, the actual adjustment is only compiled and
294 * executed when `ESP_ARDUINO_VERSION >= ESP_ARDUINO_VERSION_VAL(3, 1, 0)`. In earlier versions,
295 * the logic is disabled via preprocessor macros, allowing @ref set_local_tx_power() to work as a fallback.
296 * @param enabled true to enable (recommended), false to disable and switch to manual control.
297 */
298 /**
299 * @~Chinese
300 * @brief 使能或禁用以 RSSI 为基础的动态发射功率调节。
301 * @details 该功能**默认开启**，且**强烈建议保持开启**。启用后，客户端会在 @ref Update() 中周期性读取对端设备的
302 * RSSI，并通过滞环量化器（Hysteresis Quantizer）动态调整本地 BLE 发射功率：
303 * - 信号较好（RSSI 较高）时，降低发射功率以节省能耗并减少无线干扰；
304 * - 信号较差（RSSI 较低）时，提高发射功率以维持连接稳定性。
305 * **与手动功率的冲突：** 当动态调节开启时，通过 @ref set_local_tx_power() 设置的任何功率值都会被
306 * **覆盖**，无法生效。如果需要使用固定的手动发射功率，必须先调用
307 * `set_dynamic_tx_power_enabled(false)` 关闭此功能。
308 * @note 在 ESP32 平台上，该功能依赖 @ref NimBLEClient::getRssi()。由于在 **3.1.0 之前**的 ESP32 Arduino Core
309 * 版本中 RSSI 读数存在严重漂移（不准确），实际调节逻辑仅在 `ESP_ARDUINO_VERSION >= ESP_ARDUINO_VERSION_VAL(3, 1, 0)`
310 * 时才会编译和执行。在更早的版本中，内部已通过预处理器宏禁用动态调节，此时 @ref set_local_tx_power()
311 * 可以正常生效作为回退方案。
312 * @param enabled true 表示开启（推荐），false 表示关闭并切换为手动控制模式。
313 */
