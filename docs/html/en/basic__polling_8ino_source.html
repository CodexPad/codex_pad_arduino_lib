94 // ==========================================================================
95 // 🔴 CRITICAL: Call Update() as frequently as possible in loop()
96 // ==========================================================================
97 // • Update() processes incoming Bluetooth packets from the CodexPad
98 // • Any delay(...) or long blocking code WILL cause:
99 // - Packet loss
100 // - Input lag
101 // - Unstable connection
102 //
103 // • For real-time control, call Update() every loop iteration
104 // without any blocking operations
105 //
106 // 🔴【重要】Update() 必须在 loop() 中尽可能高频调用
107 // • Update() 负责处理来自 CodexPad 的蓝牙数据包
108 // • 任何形式的 delay 或阻塞代码都会导致：
109 // - 数据丢失
110 // - 响应延迟
111 // - 连接不稳定

115 const gamepad::input::Tracker& it = g_codex_pad_client.Update();
116 // ==========================================================================
117 // Tracker: Access button and joystick states
118 // ==========================================================================
119 // • Returned Tracker provides access to ALL gamepad inputs
120 // • Buttons → it[Button::kXXX] (bool, true = pressed)
121 // • Axes → it[Axis::kXXX] (uint8_t, 0–255)
122 //
123 // 📚 GamepadInput Library Documentation:

125 //
126 // • Tracker 可用于访问所有按钮和摇杆状态
127 // • 按钮 → it[Button::kXXX]（bool，true 表示按下）
